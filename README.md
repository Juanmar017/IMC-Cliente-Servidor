# Sistema de Cálculo IMC (Cliente - Servidor TCP)

Proyecto desarrollado en Java Swing con comunicación mediante Sockets TCP para el cálculo del Índice de Masa Corporal (IMC).

## 🚀 Estructura del Proyecto
* **ServidorIMC:** Gestiona las conexiones entrantes, procesa el peso y la altura recibidos, calcula el IMC y envía la categoría correspondiente.
* **ClienteIMC:** Interfaz gráfica para configurar la dirección IP/Puerto y enviar los datos del usuario al servidor.

## 🛠️ Tecnologías utilizadas
* **Lenguaje:** Java (JDK 8+)
* **GUI:** Swing / Form AWT
* **Protocolo:** Sockets TCP (`Socket`, `ServerSocket`)
* **IDE Recomendado:** NetBeans / VS Code
